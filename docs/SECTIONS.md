- 47 (GUI `src/lib/pm-credits.js`): the "credit" sprite needs no extension any more. Its credits (same text as the variable `credit`) are drawn into costumes `credits text 1`, `2`, … (white Sans Serif at 1/25 of the stage height, wrapped to 95% of its width, 20 lines per page so no page is taller than the stage and the renderer keeps it sharp; 16-unit empty margins above and below so fencing only ever holds a margin on the stage; rotation centre = top of the text) and `credits screen` (black, exactly the stage size). Redrawn when the credits or the stage size change (`STAGE_SIZE_CHANGED`). Scripts (built-in blocks only): the black clone fades in and makes page 1 just below the stage; each page makes the next; the last one does `broadcast credits scroll and wait`, then `credits end`. On `credits scroll` page n waits n − 1 glides (`glide to y position`), then glides up one page height at a time, the last glide only as far as needed; all pages run the same glides from the same frame, so they stay exactly one page apart. Sizes come from `height of costume` (`looks_getinputofcostume`), page number from `in (costume name) replace all "credits text " with ""`; speed = the `9` in the three glides (seconds to cross the stage). Sprites from the Animated Text version (costume `credits text`) get their credits scripts (click / clone / receive hats using those costumes) and costumes replaced, other scripts kept; the new blocks are read from a short-lived sprite; Animated Text is removed when no block uses it (PenguinMod saves every loaded extension). The old backpack script (contains `text_` blocks) is replaced. (Session 47)
- 48 (GUI `src/lib/pm-credits.js`): section 47's scripts made shorter with the same result (105 blocks in 4 scripts → 63 in 3). A full page's text is now exactly one stage high (line height = stage height / 20, page costume = stage height + 32). Each page (clone script): goes to the bottom (`y = -height of credits screen / 2`), goes to front, glides 9 s up one stage height, wears the next costume and, if it is a page, makes a clone (the new clone's script runs in the same frame, at the parent's spot, and moves to the bottom before anything is drawn), wears its own costume again, glides on by its text height (costume height − 32) at the same speed, broadcasts `credits end` if it is the last page, deletes itself. The black clone only fades in and makes page 1; `credits end` only fades it out. The click script tests `costume name contains "credits"`. Gone: `credits scroll`, the page number (`replace all`), the waiting glides, `ceiling`. Sprites with a `credits scroll` hat (section 47) are upgraded like the Animated Text ones (`needsUpgrade`); a backpack script containing `credits scroll` is replaced. (Session 48)
